What's being tracked on this page

This is a demo of analytics wiring, not a real store. Two tools sit side by side here on purpose, so you can see how each one picks up the same interactions differently.

Google Analytics (GA4)

Tracks pageviews automatically, plus the custom events fired below — button clicks, project card opens, and the newsletter form. Look for the gtag('event', …) calls in script.js.

Meta (Facebook) Pixel

Tracks the same moments as conversion signals for ad targeting and retargeting — Lead on the quote button, ViewContent on project cards. Look for the fbq('track', …) calls in script.js.

Tell us about the build

Submitting this form fires a conversion event on both tools — a useful moment to instrument on a real site, since it's the point a visitor becomes a lead.
